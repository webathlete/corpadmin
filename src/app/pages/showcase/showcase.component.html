Notifications

Reusable NotificationService (core/services/notification.service.ts) — async, app-wide toasts on top of MatSnackBar. Calls queue instead of clobbering each other, so a burst of notifications plays one at a time. The bell (top right) is <app-notification-bell> — opens a slide-in notification center for the same feed: All/Unread tabs, grouped by Today/Earlier, a "Read" button per item, and Mark all read / Clear all.

Dialogs

Generic <app-dialog> shell — header (icon + title + subtitle + close), scrollable projected body and a projected action bar. The body is pure content projection, so it takes a message, a form, a table or anything else. Open it with DialogService.open(Component | TemplateRef, { size }), which applies the standard width variants. Styling is a single small SCSS file whose tokens resolve against the host app first (--app-*) and fall back to M3 --mat-sys-*, so it themes here and drops into a plain Material app.

The shell works outside MatDialog too — no ref required

MatDialogRef is injected optionally, so the shell renders as a plain panel when it isn't inside a dialog. Useful for previewing a dialog's layout, or for reusing one body in both a drawer and a modal.

DialogService.open() accepts a TemplateRef, so a one-off dialog needs no separate component — the template keeps access to this page's state.

Job panel

Self-contained <app-job-panel> — a master–detail browser that shows a compact job list and swaps in place for one job's details (ID, name, start/end, log, status pill) with status-appropriate actions and a way back. It holds no services and reads no global styles, so it drops into any Angular Material project alongside shared/dialog. Actions here really mutate the list: start or re-run a job and it runs, clean one up and it disappears.
